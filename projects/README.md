# Projects

##  Kids Language Learning System

The Kids Language Learning System is a full-stack web and mobile educational platform designed to help children learn new languages through interactive lessons, quizzes, games, and stories.

The system supports **English, French, Spanish, and Chinese**, providing an engaging learning experience with audio pronunciation, animations, colorful illustrations, and child-friendly navigation.

### Key Features
- Interactive language lessons and quizzes
- Educational games and narrated stories
- Multilingual learning support
- Audio pronunciation and animations
- User registration and authentication
- Progress tracking and achievement badges
- Personalized learning dashboard
- Web and mobile accessibility

 ### Technologies & Tools
- **Mobile:** React Native, Expo, TypeScript, Expo Router
- **UI & Animations:** React Native SVG, React Native Reanimated
- **Backend:** REST APIs, database integration
- **Development:** Visual Studio Code, Git, GitHub, npm
- **Testing:** Expo Go, Android and iOS devices

### Project Overview
The project was initially developed as a web-based learning platform and later expanded into a cross-platform mobile application. It demonstrates practical skills in **full-stack development, mobile application development, API integration, UI/UX design, and collaborative software engineering**.

**Project Type:** Full-Stack Web & Mobile Application  
**Category:** Educational Technology (EdTech)  
**Platforms:** Web, Android & iOS

## Department Management System

Technologies:
- React
- javascript
- python
- Nextjs
- Postman
- MySql

### Repository:
https://github.com/Marychiso/DepartmentManagementSystem.git

### Description:

The Department Management System is a web-based platform that streamlines appointment scheduling and department entry requests for students. Students can book appointments with employees or apply for entry, while employees can review, approve, or reject requests through their dashboards. Approved requests generate secure QR codes for access verification, and a Super Admin manages employees and oversees system operations.


## Hornet Detection System

### Technologies:
1. Raspberry Pi
The Raspberry Pi 5 (or another Raspberry Pi model) 
Its responsibilities include:

-Capturing video from the camera
-Running the AI model (or sending images to a server)
--Sending alerts
Controlling optional hardware like traps or deterrents

### Languages
-Python (main language)
-Linux command line (basic knowledge)

2. Camera Integration

A camera continuously monitors the entrance of the beehive.
Possible cameras:
-Raspberry Pi Camera Module
-USB Webcam

The software continuously captures images or video frames for analysis.

Languages/Libraries
-Python
-OpenCV

3. Dataset Collection
Before the AI can detect hornets, it must be trained using images.
The dataset should include:

-Invasive hornets
-Honey bees
-Other insects
-Empty backgrounds

### Repository: 
https://github.com/Marychiso/hornetsystem.git


Description:
AI-powered system that uses a Raspberry Pi with a camera to detect invasive hornets near beehives in real time. A trained object detection model runs either on-device or on a remote server, processing the camera feed and triggering alerts via email upon detection. The project covers dataset collection, model training, Pi-camera integration, and building an alert pipeline.
