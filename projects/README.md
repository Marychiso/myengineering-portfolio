## Department Management System

Technologies:
- React
- javascript
- python
- Nextjs
- Postman
- MySql

Repository:
https://github.com/Marychiso/DepartmentManagementSystem.git

Description:

The Department Management System is a web-based platform that streamlines appointment scheduling and department entry requests for students. Students can book appointments with employees or apply for entry, while employees can review, approve, or reject requests through their dashboards. Approved requests generate secure QR codes for access verification, and a Super Admin manages employees and oversees system operations.


## Hornet Detection System

Technologies:
1. Raspberry Pi
The Raspberry Pi 5 (or another Raspberry Pi model) 
Its responsibilities include:

-Capturing video from the camera
-Running the AI model (or sending images to a server)
--Sending alerts
Controlling optional hardware like traps or deterrents

Languages
-Python (main language)
-Linux command line (basic knowledge)

2. Camera Integration

A camera continuously monitors the entrance of the beehive.
Possible cameras:
-Raspberry Pi Camera Module
-USB Webcam

The software continuously captures images or video frames for analysis.

Languages/Libraries
-Python
-OpenCV

3. Dataset Collection
Before the AI can detect hornets, it must be trained using images.
The dataset should include:

-Invasive hornets
-Honey bees
-Other insects
-Empty backgrounds

Repository: https://github.com/Marychiso/hornetsystem.git


Description:
AI-powered system that uses a Raspberry Pi with a camera to detect invasive hornets near beehives in real time. A trained object detection model runs either on-device or on a remote server, processing the camera feed and triggering alerts via email upon detection. The project covers dataset collection, model training, Pi-camera integration, and building an alert pipeline.
